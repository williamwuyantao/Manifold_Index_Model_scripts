# Paper figure sources

Run `python figures/reproduce.py TARGET` from the repository root. PDFs are
written to `reproduced/output/pdf/`; numerical plots also produce previews.
`all` includes every target below. The diagram target needs pdfLaTeX and TikZ.

| Paper content | Target | Source |
|---|---|---|
| Model geometry, component level sets and gradients | `diagrams` | `paper_diagrams/model_geometry.py`, `update_m2_geometry_tube.py`, `source/` vector assets |
| Phase 1: three radii, eigenvalues and score | `diagrams` | `paper_diagrams/phase1_scan.tex`, `response_preimage_slabs.py` |
| Phase 2 neighborhoods | `diagrams` | `paper_diagrams/phase2_refinement.tex` |
| Tangential/normal cylinder | `diagrams` | `paper_diagrams/local_cylinder.tex` |
| Theoretical argument roadmap | `diagrams` | `paper_diagrams/theory_roadmap.tex` |
| One-dimensional link | `diagrams` | `paper_diagrams/curve_link.tex` |
| Single-index and Meyer learning curves | `curves` | `curves.py`, retained vector panels in `pdf/curves/` |
| Bumpy geometry and response components | `bumpy-geometry`, `bumpy-maps` | `geometry.py`, `bumpy_maps.py` |
| Bumpy sample-size scaling (Figure 10) | `bumpy` | `bumpy_rates.py`, `results/bumpy_sphere/iid.jsonl` |
| Phase 2 trajectories and projection comparison | `phase2` | `phase2.py`, `results/phase2/` |
| Coupled-helix geometry, polynomial/rational components and scaling (Figure 14) | `coupled` | `coupled.py`, `data/coupled_helix/`, `results/coupled_helix/iid.jsonl` |

| Additional fixed global-tube scaling | `global-tube` | `bumpy_rates.py`, `results/global_tube/` |

The five TikZ files contain the drawings embedded in the submitted manuscript,
with a self-contained preamble. Each compiles directly with pdfLaTeX; Phase 1
also needs `MFM_m2_preimage_slabs.pdf`, generated automatically by `diagrams`.
The roadmap retains the proposition numbering in that manuscript.

Figure 1 uses a retained vector base for its cylindrical patch. Its
drawing program is unavailable. `source/` includes that PDF, the
outline coordinates and the diameter label needed by the current reconstruction.
The remaining panels and all current additions are generated by the supplied
Python programs.

The coupled response renderer outputs separate polynomial and rational
three-component figures, matching the main text and appendix. The bumpy and
coupled scaling figures use the same compact two-panel renderer. The curve
target preserves the vector data and omits the base-point-error panel;
fresh MATLAB curve runs use the same two displayed error metrics.
